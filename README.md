## 使用方式

1. 先读本文件和会议修改清单。
2. 修改前对照 MD 与 V7；有冲突时列出需求编号、两边原文和待确认问题。
3. 后续产物放到 `requirements/`，保持 `baseline/` 的两份原件不变。
4. 未获新的命名决定前继续用 V7 标识符；同名事件通过适用属性值区分，不套用 V8 名称。
5. 固定字段在文档中集中定义、逐事件引用；实际触发时应传的信息仍必须传，不能因文档省略重复文字而漏报。
