# Mint V2.0.0 字段枚举与取值规则

## 1. 先区分枚举和非枚举

- 枚举字段只有有限、可管理的取值，例如结果、状态、渠道和页面状态。
- UUID、业务ID、金额、时间、次数和版本不是枚举；这些字段只定义生成或格式规则。
- “等”“见规则”“实际值”“建议映射”“生产受控”表示列表不完整，必须标为待确认，不能直接导入GrowingIO。
- 每个枚举必须按具体事件使用；不能把一个事件的success/fail集合强行套到所有result字段。

## 4. 必须单独确认的枚举边界

- `borrower_type=first/repeat/unknown`只表示首借、复借和未知；白名单客群是否新增字段由产品和科技确认。
- `result`不是全局统一枚举。客户端校验、网络请求、后台受理、资金到账等事件各用自己的结果集合。
- `screen_code`、`step_name`、`action_name`、`next_route`等原文含“等”或“见规则”，当前值只是已知集合，不是完整生产白名单。
- 后台状态字段出现“待映射”“建议映射”时，必须取得真实状态机及历史样例后冻结。
- 大小写必须按字段原规则保留；不能自行把`PAID`改成`paid`或把`UNKNOWN`与`unknown`跨字段统一。
